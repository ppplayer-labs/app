## B. Chromium integration

YouTube defaults to ChromiumPlaybackEngine on macOS. Intent flows through the
PPPlayer facade, ChromiumYoutubePlayerController, the JavaScript iframe bridge,
CEF host IPC, accelerated Metal blits, Mach-exported IOSurfaces and Flutter
textures. MediaKit remains the local/network/radio implementation. The disabled
Chromium path reports unsupported YouTube instead of routing it to libmpv.

The wrapper document is generated by loadHtmlString using the configured HTTPS
base origin. The public `/chromium/player.html` request returned 404 during this
investigation, but that page is not downloaded to construct the player. Live
playback confirmed the generated document can load the YouTube iframe. This does
not certify future hosted-document compatibility or all YouTube media variants.

Reproduced Release defect: audio advanced and was audible, but the full player
and mini-player were blank. Accelerated callbacks and successful IOSurface port
lookups were present. ResizeBrowser replaced its IOSurface ring while retained
Metal destination textures still pointed to the previous generation. The patch
releases that destination cache before replacing the ring. Paint and resize run
on the CEF UI thread; current blits complete synchronously before return.
